# שלוחת חיפוש קולי במכלול - ימות המשיח

מודול `type=api` לימות המשיח: המתקשר אומר מה הוא מחפש, המערכת מתמללת
את ההקלטה, מחפשת באתר [המכלול](https://www.hamichlol.org.il) (MediaWiki),
משמיעה עד 5 תוצאות, והמתקשר בוחר אחת בהקשה - ואז המערכת מקריאה לו
את תמצית הערך.

## מבנה הפרויקט

```
api/
  michlol.js         - ה-endpoint הראשי שימות קורא אליו (state machine)
  transcribe.py       - שירות תמלול קול-לטקסט (הועתק מפרויקט קיים שלכם)
  requirements.txt    - תלויות Python עבור transcribe.py
lib/
  michlolApi.js        - חיפוש ושליפת תמצית מה-API של המכלול
  yemotResponse.js     - בניית מחרוזות read / id_list_message, פיצול טקסט
  yemotFiles.js         - הורדת קובץ הקלטה דרך DownloadFile
  yemotSession.js      - שימוש בטוקן המתקדם שמוגדר בשלוחה
ext.ini.example        - דוגמה להגדרת השלוחה בימות
.env.example           - תיעוד: אין צורך במשתני סביבה
vercel.json            - הגדרות Vercel (timeout לפונקציה)
package.json
```

## התקנה ופריסה

1. **להעלות את הריפו ל-GitHub** ולקשר אותו לפרויקט ב-Vercel (כפי
   שציינתם - clone/push לריפו, ואז "Import Project" ב-Vercel).
2. Vercel יזהה אוטומטית גם את `api/michlol.js` (Node.js) וגם את
   `api/transcribe.py` (Python) כשתי serverless functions נפרדות
   באותו פרויקט - אין צורך בשני פרויקטים נפרדים ב-Vercel, אלא אם
   תעדיפו זאת.
3. אין צורך להגדיר משתני סביבה ב-Vercel.
4. לקחת את כתובת ה-deployment (`https://your-project.vercel.app`) ולעדכן את `api_link` ואת הטוקן המתקדם בהגדרות השלוחה; ראו `ext.ini.example`. שירות התמלול נקרא אוטומטית מ-`/api/transcribe` באותו deployment.

## הגדרות נדרשות

אין צורך במשתני סביבה ב-Vercel: לא מספר מערכת, לא סיסמת מערכת, לא טוקן שרת ולא כתובת נפרדת לשירות התמלול.

יש להגדיר את הטוקן המתקדם בהגדרות שלוחת `type=api` כפרמטר `YemotAdvancedToken`. דוגמת הגדרה:

```ini
type=api
api_link=https://YOUR-VERCEL-PROJECT.vercel.app/api/michlol
api_add_0=YemotAdvancedToken=YOUR_ADVANCED_YEMOT_TOKEN
```

יש להחליף את כתובת השרת ואת ערך הדוגמה בטוקן האישי. הקוד קורא את הערך מהבקשה שמגיעה מימות ומשתמש בו עבור `DownloadFile`.

שירות התמלול נמצא באותו פרויקט, בכתובת `/api/transcribe`, ולכן אין צורך במשתנה `TRANSCRIBE_SERVICE_URL`.

**הערת הרשאות:** יש לוודא שהטוקן המתקדם אכן מורשה להפעיל את פקודת `DownloadFile` ב-Management API של ימות. אם סוג הטוקן אינו נתמך בפקודה זו, צריך להשתמש במנגנון הרשאות נתמך של ימות; הקוד אינו יכול לעקוף הרשאות ספק.

## דברים לבדוק בפועל לפני הפעלה בפרודקשן

אלו דברים שסומנו בהנחיות כ"לא ידוע ואין לנחש" או שתלויים בשרת/גרסה
הספציפיים שלכם - יש לבדוק אותם בשיחת טלפון אמיתית לפני הפעלה:

1. **האורך המקסימלי לקטע `t-` בודד בתגובת `id_list_message`.** בקוד
   (`lib/yemotResponse.js`) מוגדר ערך זהיר התחלתי של כ-600 תווים
   לקטע (`MAX_CHUNK_LENGTH`), עם פיצול לפי סוף משפט. יש לבדוק
   בטלפון אם קטעים ארוכים יותר עובדים, או שצריך לקצר את הערך.
2. **פורמט נתיב הקובץ ל-`DownloadFile`.** יש לוודא בבדיקה בפועל אם נדרשת קידומת כגון `ivr2:`; ברירת המחדל בקוד היא נתיב ללא קידומת.
3. **פורמט ותדר ההקלטה שימות שומר בפועל** (סוג wav, sample rate) -
   לוודא שתואם למה ש-`transcribe.py` (ספריית SpeechRecognition)
   מצפה לקבל, ובמידת הצורך להוסיף המרה.
4. **הרשאות הטוקן.** לוודא שהטוקן המתקדם שמוגדר בשלוחה מורשה לבצע `DownloadFile` על תיקיית ההקלטות.
5. **זמן התגובה הכולל** (הורדת קובץ + תמלול + חיפוש) ביחס לזמן
   ההמתנה שימות מאפשר לתגובת שרת לפני ניתוק/timeout - אם יש צורך,
   ניתן להגדיר למתקשר מוזיקת המתנה (`api_wait_answer_music_on_hold=yes`).
6. **התנהגות בשיחה שנייה/מקבילה לאותו `ApiCallId`** - כרגע הפתרון
   ב"שלב ג" מריץ חיפוש שני במכלול (ולא שומר את רשימת התוצאות בין
   קריאות), כדי להישאר ללא בסיס נתונים כפי שהתבקש. במקרה הנדיר שבו
   תוצאות החיפוש משתנות בין שתי הקריאות (עדכון באתר בדיוק בין
   ההקלטה לבחירה), ייתכן חוסר-התאמה קל. אם זה קריטי, אפשר בעתיד
   להוסיף קאש זמני (למשל לפי `ApiCallId`) - לא מומש כעת כי זה
   חורג מהדרישה ל-stateless.

## בדיקות מומלצות

- שיחה תקינה מקצה לקצה: הקלטה ברורה → תמלול → תוצאות → בחירה → הקראה.
- הקלטה שקטה/לא ברורה - וידוא שחוזרים לבקשת הקלטה מחדש בלי קריסה.
- חיפוש שלא מחזיר תוצאות כלל.
- ניתוק מתקשר באמצע ההקלטה (`save on disconnect` מוגדר `yes`).
- הקשת בחירה לא תקינה (מספר שלא מופיע ברשימה).
- Timeout בקריאה ל-transcribe.py (שירות איטי/לא זמין).

## רישיון השימוש ב-API של המכלול

ה-API של המכלול ציבורי וסטנדרטי (MediaWiki), אך מומלץ לשלוח כותרת
`User-Agent` מזהה (כבר מוגדר בקוד) ולא להציף את השרת בקצב גבוה
מדי של בקשות - ראו את מדיניות השימוש שלהם באתר אם קיימת.
