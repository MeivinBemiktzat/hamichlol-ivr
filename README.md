# מערכת IVR לחיפוש והאזנה לערכים

קו טלפוני שמאפשר לחפש ערכים אנציקלופדיים ולהאזין להם, על גבי מערכת ימות המשיח.
המתקשר אומר את שם הערך בקול או מקיש אותו, שומע רשימת תוצאות, ומאזין לערך
שנחלק למקטעים נוחים לשמיעה.

## מה הקו עושה

- **חיפוש קולי** — המתקשר אומר את שם הערך, וימות מתמללת אותו לטקסט.
- **חיפוש בהקשה** — למי שמעדיף להקיש במקלדת הטלפון.
- **האזנה מנווטת** — מקטע הבא, חזרה, מקטע קודם, חזרה לתחילת הערך.
- **מועדפים והיסטוריה** — שמירת ערכים וחזרה אליהם בשיחה הבאה.
- **הגדרות אישיות** — שיטת חיפוש, מספר תוצאות, וכיבוי שמירת היסטוריה.
- **עזרה קולית** — הסבר על השימוש בקו.

## הפעלה מהירה

```bash
npm test                       # 107 בדיקות, בלי גישה לרשת
npx vercel dev                 # הרצה מקומית
node scripts/smoke.js <כתובת>  # בדיקת עשן אחרי פריסה
```

אין תלויות חיצוניות. המערכת רצה על Node 20 ומעלה עם ספריות הליבה בלבד.

## התקנה

המדריך המלא נמצא ב־[INSTALLATION.md](INSTALLATION.md), והוא מכסה את כל
השלבים: פריסה ב-Vercel, הגדרת אחסון, והגדרת השלוחה בימות המשיח.

בקצרה, שלושה שלבים:

1. פריסה ב-Vercel, שמייצרת כתובת לפרויקט.
2. הגדרת שלוחה בימות מסוג `type=api` שמצביעה לכתובת הזו.
3. הגדרת זיהוי הדיבור בשלוחה, כדי לאפשר חיפוש קולי.

אחסון והיסטוריה הם רשות. בלעדיהם הקו עובד במלואו, רק בלי לזכור את המשתמש.

## שתי מגבלות שחשוב לדעת עליהן מראש

**הגישה למכלול לא אומתה.** האתר מחזיר שגיאת 403 ודף אתגר של Cloudflare לכל
פנייה מהשרת. המימוש מניח ממשק מדיה-ויקי סטנדרטי, וזו הנחה מתועדת שלא נבדקה
בפועל. אם הפריסה נתקלת בחסימה, אפשר לעבור זמנית לוויקיפדיה העברית בשינוי
משתנה סביבה אחד, ובמקביל לפנות למפעילי המכלול ולבקש גישה. הפרטים
ב-[docs/RESEARCH.md](docs/RESEARCH.md) וב-[TROUBLESHOOTING.md](TROUBLESHOOTING.md).

**היסטוריה ומועדפים דורשים הגדרה.** בלי `USER_ID_SALT` ובלי אחסון, הקו עובד
אבל אינו זוכר דבר בין שיחות. זו התנהגות מכוונת, כדי לא לייצר מזהי משתמש
חלשים כברירת מחדל.
